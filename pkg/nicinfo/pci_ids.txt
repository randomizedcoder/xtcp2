# Embedded PCI id subset for the xtcp2 fleet NICs.
#
# Format (one entry per line): <vendorhex>:<devicehex> <model...>
#   - vendor and device are bare 4-digit hex (no 0x prefix), lowercased.
#   - everything after the first space is the human model string.
# Blank lines and lines starting with '#' are ignored.
#
# Kept deliberately small: the production container rootfs is read-only, so we
# embed just the fleet's known ids rather than shipping the full pci.ids DB.
